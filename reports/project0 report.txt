3. From what I saw in the source code, the Thread class in Nachos is basically the object that represents one single thread running in the system. Each thread keeps track of its own stack and its own saved set of registers so that the system can pause it and pick it back up later without losing its place. Some of the main functions the class provides are Fork, which creates a new thread and gets it ready to run, Yield, which lets a thread give up the CPU voluntarily so another thread can run, Sleep, which blocks a thread until something wakes it back up, and Finish, which is called when a thread is done and needs to be cleaned up. Threads can be in different states throughout their life, like ready, running, or blocked, and the scheduler is what decides which thread actually gets to run next whenever the CPU is free. This assignment along with some research gave me a good idea on how the thread class works so I am interested to see where I will use it in future endeavors.
